# ❄️ Winter Arc — Installable PWA

Updated PWA build. Upload these files to the ROOT of the `main` branch:

- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

GitHub Pages should remain set to `main` + `/ (root)`.

After GitHub Pages redeploys:
1. Open the site in Chrome.
2. Refresh once.
3. Chrome menu → Install and create shortcut.
4. Choose **Install**. It should now be available.

The app stores your tracker data locally in the browser.
